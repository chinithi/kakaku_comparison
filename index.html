A. GitHub Gist クラウド同期（最速1タップ） PC⇔スマホ自動同期

GitHubのPersonal Access Token（gist権限のみ）を設定すると、非公開GistをクラウドDB代わりにしてPCとスマホを1タップで同期できます。

Gist ID
B. Google Drive / クラウドフォルダ連携 トークン不要

スマホの共有メニュー（Googleドライブへ保存・LINE Keep・AirDrop等）や、PCのGoogleドライブ同期フォルダを使って直接JSONファイルを読み書きします。

C. 同期コードで即コピー移行

全データを圧縮文字列（Base64）としてコピーし、LINEやメモ帳経由で別端末に貼り付けて即座に復元できます。
